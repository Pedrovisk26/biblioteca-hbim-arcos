# Política de segurança e privacidade

## Escopo

Use o canal privado de relato de vulnerabilidade do GitHub para comunicar:

- credenciais ou segredos incluídos por engano;
- dados pessoais ou metadados que não deveriam estar públicos;
- arquivos maliciosos ou adulterados;
- divergências entre os checksums publicados e os downloads; ou
- riscos de segurança associados à abertura dos arquivos distribuídos.

Não publique credenciais, dados pessoais ou detalhes exploráveis em uma *issue* pública. Na página do repositório, abra a aba **Security** e selecione **Report a vulnerability**.

Os autores procurarão confirmar o recebimento e, quando necessário, retirar temporariamente o artefato afetado enquanto realizam a análise. Este projeto disponibiliza dados de pesquisa, não um produto com garantia de suporte ou prazo de correção.
