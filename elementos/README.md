# Fichas dos elementos

Cada diretório usa o ID permanente do elemento e contém `README.md`, `metadados.json` e `CHANGELOG.md`.

Consultar o [catálogo](../catalogo/README.md) para navegar pelas cinco fichas. Os arquivos pesados ficam nos [pacotes de famílias, malhas e vídeos](../releases/v0.1.0/README.md).

As fichas dos [modelos IFC4](../releases/v0.2.0/README.md) não ficam neste diretório: cada uma está dentro do respectivo pacote ZIP.
