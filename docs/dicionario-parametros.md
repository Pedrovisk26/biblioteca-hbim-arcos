# Dicionário de parâmetros Revit

Este documento define o registro dos parâmetros das famílias. Os parâmetros internos existentes não foram renomeados nem examinados nesta organização documental.

## Campos para registrar

| Campo | Conteúdo |
| --- | --- |
| Nome exato | Nome encontrado na família, preservando a grafia existente |
| Significado | Grandeza ou função representada |
| Tipo de dado e unidade | Confirmados no software |
| Aplicação | Parâmetro de tipo ou de instância |
| Obrigatoriedade | Obrigatório ou opcional, com justificativa |
| Regra ou fórmula | Fórmula e dependências, quando existirem |
| GUID | Identificador, quando for parâmetro compartilhado |
| Elemento e componente | ID e família aos quais se aplica |
| Introdução e revisão | Versão, responsável e data da conferência |

## Estado do levantamento

O levantamento individual dos parâmetros está pendente para os cinco elementos da versão 0.1.0. Não assumir compatibilidade entre famílias pela semelhança dos nomes dos parâmetros. Atualizar este dicionário e os metadados do elemento na mesma contribuição quando as famílias forem examinadas.
